# Solicitud de creación del repositorio `naufragios`

**Asunto:** Creación del repositorio GitHub `naufragios`

Hola,

Quiero crear un repositorio GitHub llamado `naufragios` para desarrollar una herramienta de investigación histórica sobre naufragios en Canarias y sus rutas atlánticas hasta el año 1800.

El repositorio incluirá:

- búsqueda documental multilingüe;
- un agente investigador de fuentes;
- agentes de extracción, relación y contraste de evidencias;
- fichas de barcos, cargas, personas, rutas y naufragios;
- mapa histórico con zonas de incertidumbre;
- registro de fuentes, transcripciones y referencias verificables;
- pruebas automáticas para comprobar las búsquedas y las relaciones entre agentes;
- documentación de instalación, uso y límites del sistema.

La primera versión trabajará con datos públicos, enlaces y metadatos documentales. No se incorporarán credenciales, documentos privados ni coordenadas sensibles en el repositorio. Las posiciones exactas de posibles pecios quedarán protegidas y separadas de la vista pública.

Necesito que el repositorio tenga:

- rama principal `main`;
- licencia pendiente de decisión;
- archivo `README.md`;
- estructura inicial para código, datos de prueba, documentación y pruebas;
- GitHub Actions para ejecutar las pruebas automáticamente;
- protección de secretos mediante variables de entorno, sin incluir claves en el código.

Nombre propuesto: `naufragios`

Descripción propuesta: `Herramienta auditable para investigar naufragios históricos de Canarias hasta 1800.`

Cuando esté creado, agradecería recibir la URL y los permisos necesarios para trabajar en el repositorio.

Gracias.

Un saludo,

Fernando
